# Exactitud–Precisión Experimental

Aplicación Streamlit para comparar hasta tres series de mediciones experimentales
de una misma magnitud.

## Ejecutar localmente

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Despliegue en Streamlit Community Cloud

- Repositorio: este repositorio
- Rama: `main`
- Archivo principal: `app.py`
- Python recomendado: 3.12

No requiere secretos ni servicios externos.
